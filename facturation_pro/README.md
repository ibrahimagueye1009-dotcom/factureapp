# Facturation Pro (Flutter)
1. Installer Flutter, puis dans ce dossier : `flutter create . --org sn.facturation --project-name facturation_pro`
   (génère les dossiers android/ et ios/ sans toucher à lib/ ni pubspec.yaml)
2. `flutter pub get`
3. iOS : ajouter dans ios/Runner/Info.plist la clé NSPhotoLibraryUsageDescription (accès galerie pour logo/tampon).
4. `flutter run`
